MY MUSIC — HOME SCREEN VERSION

This package is prepared as a Progressive Web App (PWA).

How to put it on your iPhone Home Screen:
1. Publish the contents of this folder on an HTTPS web host.
   GitHub Pages is a free option for public repositories.
2. Open the published site in Safari on your iPhone.
3. Tap Share.
4. Tap "Add to Home Screen".
5. Tap "Add".

Important:
- The app itself is free and has no ads or artificial usage limits.
- It is designed for music you own or are licensed to use.
- Your imported music is stored locally in the browser/device.
- Safari/iOS may impose storage and background-playback limits.
- A live HTTPS URL is required for a service worker/PWA install.

GitHub Pages:
Create a public repository, upload these files, then enable
Settings → Pages → Deploy from a branch → main / root.
GitHub says Pages is available on GitHub Free for public repositories.

This package does NOT publish itself to the internet; a hosting account is
needed to give it a live URL.
